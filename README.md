# DDD-Anime-Watch

This is an example project demonstrating Domain-Driven Design (DDD) principles and architecture, using an **Anime Store** as the practical exercise domain.

## 📖 Overview

The goal of this project is to apply DDD tactical and strategic design patterns (entities, value objects, aggregates, domain services, repositories, bounded contexts, etc.) to a real-world simulation of an Anime Store.

## 🛠️ Tech Stack

- **Java**
- **Spring Boot**
- **Gradle**
- **Lombok**

## 🚀 Getting Started

### Prerequisites

- Java 21+ / JDK installed
- Gradle (or use the included `./gradlew` wrapper)

### Build and Run

```bash
# Build the project
./gradlew build

# Run the application
./gradlew bootRun
```
